# Release copy conventions

KeyBridge is presented as a finished product. All application text, Store fields, reviewer instructions, screenshots, privacy text and public product descriptions use English.

Describe the available behavior directly, using present-tense product descriptions and useful operation instructions. Keep engineering status labels and checklists out of release copy and certification notes.

Describe supported operating conditions accurately: Windows 11 x64, ENG US, ordinary-permission application scopes, Ctrl plus letter targets with optional Shift, user confirmation, and native input behavior outside those conditions. Use helpful setup language such as "Confirm this shortcut" instead of presenting a user's initial configuration as a product defect.

Keep factual engineering records accurate. Only describe a check as passed when its result was actually observed. Avoid promises of universal compatibility or a guaranteed certification outcome.
